# Calculator Project

A simple Python calculator with basic operations:
- Add
- Subtract
- Multiply
- Divide (with zero division handling)

## Requirements
- Python 3.x
- pytest (install with `pip install pytest`)

## Project Workflow

- **Development in VS Code**  
  Write and edit code in `calculator.py` and tests in `test_calculator.py`.

- **Version Control in Git Bash**  
  Use Git Bash for commands:
  - `git add <file>` → stage changes
  - `git commit -m "message"` → save snapshot
  - `git push origin main` → publish to GitHub

## How to Run

Open terminal in project folder:
```bash
cd calculator-project
python calculator.py

How to Test
Run unit tests with pytest:
pip install pytest
pytest
Green = all tests passed
Red = fix code and run again
